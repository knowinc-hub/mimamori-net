## 追記（2026-07-16）: 実機確認フィードバックによる投稿モデルの変更

- 投稿ボタンを「＋ 捜索依頼をする」に変更し、ウィザードは**捜索依頼専用**（4ステップ）に
- **発見報告・情報提供は独立した投稿を廃止**。捜索依頼カード上のボタンから追加し、依頼にひも付く「寄せられた情報」タイムラインとして表示
- **「見かけた」のワンタップ加算を廃止**。場所（必須）・いつ頃・様子を入力する目撃情報フォームに変更し、数字ではなく内容で信頼性を担保。「反応数」カウンタは削除し、実際に寄せられた情報の件数・内容を表示
- 発見報告が届くと依頼カードに「ご家族（投稿者）は確認のうえ解決処理を」の案内を表示
- 解決時はタイムラインの内容も含めて削除（履歴には件数のみ）

## 実装内容

### 技術基盤
- 単一HTMLモック → **Vite + React 19 + TypeScript + Tailwind CSS 4 + PWA** に全面移行
- 旧モックは `docs/prototype/index.html` にアーカイブ（文言・データ項目は新実装に引き継ぎ）
- データアクセスを **Repository インターフェース**（`src/data/repository.ts`）に分離。Phase 2 は `LocalRepository`（localStorage）を Firestore 実装に差し替えるだけで移行可能
- GitHub Actions による main → GitHub Pages 自動デプロイを追加（`.github/workflows/deploy.yml`）

### UI/UX 改善（指示書の要件との対応）
- **モバイルファースト**: 375px基準・下部タブナビ維持・タップ領域は全ボタン44px以上
- **配色刷新**: ダーク基調 → ライトテーマ（白＋teal基調）。ユーザー確認済み。警告色（赤）は「捜索中」バッジと110番導線のみに限定
- **絵文字アイコン全廃** → lucide-react の SVG アイコン＋テキストラベル併記
- **ホーム画面**: 最上部にステータスカード（「現在、捜索依頼はありません」/「捜索中の依頼が○件」）。統計は控えめに最下部へ。全依頼カードに「発生からの経過時間」「最終更新」を常時表示
- **投稿フロー**: 1枚モーダル → **ステップ式ウィザード**（捜索依頼は5ステップ、その他3ステップ、各ステップ入力3項目以内）
  - 警察届出確認ステップ: 「届出済み」チェック必須＋受理番号（任意）。未届けの場合は **110番を促す画面**（`tel:110` リンク）を挟む
  - **下書き自動保存**: 入力途中で閉じても、次回起動時に「続きから再開」を提案
  - 確認画面に「エリア内メンバーのみに共有・解決後に自動削除」を明示
- **履歴画面**: プライバシー保護の説明文を先頭に固定。「個人情報は削除済み」バッジ付きカード（日時・エリア・所要時間・反応数のみ）
- **転載抑止**: 依頼写真に「みまもりネット限定共有」透かし＋pointer-events無効化＋ドラッグ禁止。限界は README に明記
- **3状態設計**: 全画面にローディング（スケルトン）・空状態・エラー状態（再試行ボタン付き）を実装
- **PWA**: マニフェスト＋Service Worker（Workbox precache）、ホーム画面追加バナー（初回のみ・iOS向け手順案内あり）、オフライン時バナー
- **アクセシビリティ**: ベース16px・コントラスト4.5:1以上・全フォームにlabel＋インラインエラー・role/aria対応・フォーカス管理（ウィザードのステップ切替時に見出しへフォーカス）

### 設計原則の遵守（データ層でも保証）
- 解決時に `LocalRepository.resolvePost()` が投稿本体を**物理削除**し、履歴には `{日時, エリア, 所要分数, 反応数}` のみ保存（Phase 2 の private サブコレクション隔離と同じ思想）
- OGP はアプリの一般紹介のみ。SNS共有導線なし
