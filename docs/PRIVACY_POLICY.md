- 本サービスはアクセス解析・広告目的のCookie等は使用していません。

## 2. 利用目的

1. 会員の本人確認、登録の承認、アカウント管理のため
2. 捜索依頼・目撃情報等を、対象エリア内の承認された会員に共有するため
3. 通知の配信のため（通知機能の提供開始後）
4. 不正利用の防止、通報への対応のため
5. 本サービスの運営に必要な連絡のため

## 3. 第三者への提供・共有の範囲

1. 捜索依頼の詳細情報（氏名・特徴・写真・連絡先）は、**投稿と同じエリアの承認済み会員のみ**が閲覧できます。エリア外の会員には場所・日時等の概要のみが表示されます。
2. 未登録者・未承認者は、依頼情報を一切閲覧できません。
3. 上記のほか、次の場合を除き、個人情報を第三者に提供しません。
   - 警察等からの法令に基づく照会・要請がある場合
   - 人の生命・身体の保護のために必要で、本人の同意を得ることが困難な場合

## 4. 外部サービスの利用（取扱いの委託）

本サービスは以下の外部サービスを利用しており、データはこれらのサーバに保存されます。

| サービス | 用途 | 提供者 |
|---|---|---|
| Firebase（Authentication / Cloud Firestore） | 認証・データ保存 | Google LLC |
| GitHub Pages | アプリの配信 | GitHub, Inc. |

いずれも外国（主に米国）にある事業者であり、各社のプライバシーポリシーおよびセキュリティ基準に基づいて管理されます。【個人情報保護法28条（外国第三者提供）の整理について専門家に確認】

## 5. 保存期間と削除（本サービスの基本設計）

1. **捜索依頼が「解決」となった時点で、写真・氏名・特徴・連絡先・寄せられた情報の内容は削除されます。** 解決の記録として、日時・エリア・寄せられた情報の件数のみが保存されます。
2. 解決処理が行われないまま長期間経過した依頼は、投稿者への確認のうえ自動的に終了・削除する仕組みを導入予定です（導入時期: 通知機能の提供と同時）。
3. 会員が退会を希望する場合、下記窓口への連絡により、アカウント情報を削除します。【退会機能のアプリ内実装は今後の課題】
4. 通報の記録は、対応の検証のため対応完了後も一定期間保存します。

## 6. 安全管理措置

1. データへのアクセスは、認証された会員のみに、アクセス制御ルール（Firebase Security Rules）により制限しています。アクセス制御ルールは自動テストにより検証しています。
2. 写真には転載抑止の透かしを表示し、保存操作を抑止する設計としています。ただし**スクリーンショット等による複製を完全に防ぐことは技術的に不可能**であり、利用規約で転載を禁止するとともに、承認制の会員管理によりリスクを低減しています。
3. 管理者権限は必要最小限の人数に限定します。
